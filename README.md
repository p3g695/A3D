# Aether3D Game Engine

A modern 3D game engine built from scratch. Features real-time rendering, an interactive scene viewport, procedural sky environments, and 3D asset pipeline tools.

---

## Key Features

* **Real-Time Viewport Window:** Built-in window system initialized with a dynamic blue sky, procedural realistic clouds, and a standard gray 3D grid/baseplate.
* **Scene Hierarchy Panel:** Interactive UI on the far-right displaying named scene objects, entities, and components.
* **Asset Pipeline:** Native support for importing and exporting 3D models (`.obj`, `.fbx`, `.gltf`).
* **In-Engine Testing:** Embedded **Play** button to instantly toggle runtime simulation mode directly in the editor window.
* **Modular Architecture:** Clean folder separation for Core, Rendering, Modeling, and Scripting subsystems.
